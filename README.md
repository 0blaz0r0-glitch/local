# 🛰️ Мини-сайт для проверки работы по локальной сети

Лёгкий веб-сервис на **чистом Python** (без внешних зависимостей) с мини-сайтом
для диагностики локальной сети: пинг сервера, мониторинг задержки, тест скорости
канала и проверка доступности других устройств в сети.

## 📁 Структура проекта

```
.
├── server.py          # HTTP-сервер (только стандартная библиотека Python)
├── static/
│   ├── index.html     # Мини-сайт (страница проверки)
│   ├── style.css      # Оформление
│   └── app.js         # Логика проверок в браузере
└── README.md          # Эта инструкция
```

## ✅ Требования

- **Python 3.7 или новее** (проверить: `python3 --version`)
- Никаких pip-пакетов устанавливать не нужно — используется только стандартная библиотека.

## 🚀 Запуск

### 1. На компьютере-сервере

```bash
cd <папка_проекта>
python3 server.py
```

По умолчанию сервер слушает на всех интерфейсах (`0.0.0.0`) порту **8000**.
В консоли будут выведены готовые ссылки для открытия:

```
============================================================
  Мини-сайт проверки локальной сети запущен
============================================================
  Локально:        http://localhost:8000/
  По сети:         http://192.168.1.50:8000/
------------------------------------------------------------
```

Другие компьютеры в локальной сети открывают в браузере ссылку **«По сети»**
(IP-адрес и порт сервера).

### 2. Параметры запуска

```bash
# Другой порт
python3 server.py --port 8080

# Только для локального доступа (без выхода в сеть)
python3 server.py --host 127.0.0.1

# Справка по всем опциям
python3 server.py --help
```

### 3. Остановка

Нажмите `Ctrl+C` в окне терминала, где запущен сервер.

## 🔍 Как узнать IP-адрес сервера в локальной сети

- **Windows:** `ipconfig` → строка «IPv4-адрес» (обычно вида `192.168.x.x`)
- **Linux / macOS:** `ip a` или `ifconfig` (обычно интерфейс `eth0` / `enp...` / `en0`)

Сервер сам печатает найденные IP-адреса при запуске — можно просто скопировать ссылку.

## 🧪 Что умеет мини-сайт

| Раздел | Что проверяет | API-эндпоинт |
|---|---|---|
| 1. Ping | Доступность сервера и задержка ответа | `GET /api/ping` |
| 2. Мониторинг | Стабильность соединения (график задержки каждые 2 с) | `GET /api/ping` |
| 3. Информация | Хост, IP-адреса, аптайм, число запросов | `GET /api/info` |
| 4. Скорость | Пропускная способность канала (скачать 256 КБ – 5 МБ) | `GET /api/download?size=<байт>` |
| 5. Проброс хоста | Доступность другого устройства в сети (TCP connect) | `GET /api/probe?host=<хост>&port=<порт>` |

Примеры проверки через `curl` (без браузера):

```bash
curl http://localhost:8000/api/ping
curl http://localhost:8000/api/info
curl -o /dev/null "http://localhost:8000/api/download?size=1048576" -w "%{time_total}s\n"
curl "http://localhost:8000/api/probe?host=192.168.1.1&port=80"
```

## 🔧 Если не открывается с другого компьютера

1. **Проверьте, что компьютеры в одной сети** (одна подсеть, например `192.168.1.x`).
2. **Брандмауэр** должен пропускать входящие подключения на выбранный порт:
   - Windows: «Брандмауэр Защитника Windows» → разрешите правило для `python.exe`
     или команда (от администратора):
     ```bat
     netsh advfirewall firewall add rule name="LAN Check 8000" dir=in action=allow protocol=TCP localport=8000
     ```
   - Linux (ufw): `sudo ufw allow 8000/tcp`
3. **Порт занят?** Запустите на другом порту: `python3 server.py --port 8080`.
4. Проверьте доступность с клиента: `ping <IP-сервера>` и `curl http://<IP>:8000/api/ping`.

## 💡 Запуск как фоновая служба (необязательно)

**Linux (temp-file / nohup):**
```bash
nohup python3 server.py > lancheck.log 2>&1 &
```

**Windows (в отдельном окне):**
```bat
start /min python server.py
```
